# Contributing to EIGA

Thanks for contributing.

## Principles

EIGA values privacy, visual quality, accessibility, and simplicity.

Before adding a feature, ask whether it strengthens the core experience of exploring a personal cinema map.

## Development

Use the versions and scripts declared by the repository's package manager.

Run:

```bash
npm install
npm run dev
npm run lint
npm run build
```

Do not commit environment files or user media exports.

## Pull requests

Include:
- what changed
- why it changed
- how it was tested
- screenshots/video for visual changes
- any privacy or performance considerations

Keep pull requests focused.
