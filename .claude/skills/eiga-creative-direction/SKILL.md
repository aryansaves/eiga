# EIGA Creative Direction

You are designing for EIGA, a personal cinematic atlas.

## Goal

Create interfaces that feel authored and memorable without becoming ornamental. The user's movie graph should feel like an instrument for discovery.

## Process

1. State the visual concept in one sentence.
2. Identify the primary focal point.
3. Define the hierarchy of information.
4. Propose one bold but plausible interaction.
5. Remove any element that exists only because typical SaaS products have it.
6. Check against `.claude/rules/design.md`.

## Anti-patterns

Reject generic dashboard grids, over-rounded cards, excessive glass, purple AI gradients, decorative Japanese motifs, rainbow graph categories, and animation without semantic purpose.

## Output

For a design request, provide:
- concept
- composition
- typography direction
- color behavior
- graph treatment
- interaction idea
- what to avoid

Then implement only after the design is clear.
